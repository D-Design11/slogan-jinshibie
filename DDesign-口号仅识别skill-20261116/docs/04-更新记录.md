# v0.3.3 · 2026-11-16

根据用户后续确认更新：主标题固定必填，空值、非字符串及仅空白输入返回 `TITLE_REQUIRED`；副标题和二维码不增加全局必填。移除 SVG 预览与 PNG 导出中的系统 DEMO 水印，继续采用 PNG、72 dpi。同步规则配置、浏览器运行时与验证脚本，原排版数值和品牌资产不变。

审核流程拆为同包的独立 `didi-design-audit` Skill，生成 Skill 交接需求、模版版本、布局证据和真实产物；审核返回绑定文件指纹的报告。此拆分没有实现网站调度或新增二维码图片绘制、解码等底层能力。

# v0.3.2 · 2026-11-16

本次基于 `DDesign-规则包-20261110` 更新，要求来源为用户于 2026-11-16 的明确指示。

| 项目 | 原配置 | 更新后 |
| --- | --- | --- |
| 主标题 | HYQiHei-70S；组件映射为 proposed | HYQiHei-65S；组件映射为 user_confirmed |
| 副标题 | HYQiHei-50S | 明确保留 HYQiHei-50S |
| 图片交付 | 引擎有 PNG 方法，未明确统一成品格式 | 成品统一 PNG，SVG 用于内部预览 |
| 图片密度 | 未写入指定密度 | 72 dpi；PNG 写入 pHYs 元数据 |
| 输出尺寸 | 固定 1500 像素宽 | px 保留输入；mm 按 72 dpi 换算并四舍五入 |
| 字体映射 | 引擎常量与配置分开维护 | 引擎从 typography 读取 family |
| 预览页面 | 仅浏览 | 增加 PNG（72 dpi）下载 |

同步更新规则 JSON、组件绑定、浏览器运行时、说明文档和校验。主标题 65S 与副标题 50S 使用包内原始 OTF，均以独立 family 注册，不使用伪加粗；模板字号、行高、图文比例及其余原有规则继续沿用。

PNG 密度以整数像素/米存储。72 dpi 写为横纵各 2835 像素/米，部分软件会显示为约 72.009 dpi。该要求仅应用于导出成品，原始素材不重采样、不改写。

原始提取来源与哈希保存在 manifest.json 的 copied_files 中；本次文件清单与哈希另存 current_files，可用于校验更新包完整性。validation-report.json 记录实际执行的检查。
