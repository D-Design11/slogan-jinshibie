# 网区项目模版制作

仅在执行 `template_authoring` 时读取本文；共用字段见 [数据与接入约定](contracts.md)。

## 上传主视觉

网站或本地任务提供本次实际主视觉、所属网区与项目及制作者身份。读取真实文件/素材引用，不使用示例图顶替。网站上传尚未接入时可制作本地草稿，但不宣称已入资产库。

主视觉是供版式使用的图像素材。只有一张包含文字、Logo 的合成海报时，不能直接认定它具备可替换文本结构；应说明哪些内容已嵌在图中，需要无字主视觉或可编辑素材才能避免重复排字。

## 选择版式

制作者明确选择基础版式 S/M/L/XL、品牌识别排列和用于验收的预览规格。未选择时可提出候选方案，确认前不将候选当作已定稿。

基础版式规则沿用当前包；制作者不能仅通过填写任意 JSON 参数绕过尚未支持的版式。主/次信息口号和通栏横线不在当前范围。

定义默认主副标题、默认二维码及需要固定展示的内容，主标题固定必填，`required_fields` 只能追加项目要求，不能取消主标题要求。城市的内容编辑权限固定为主标题、副标题和二维码，其余内容及版式锁定。二维码支持链接和图片两种任务输入；实际预览图片模式需要对应适配。

城市输出规格采用网站的“类型分组＋预设多选＋自定义＋新增类型”形式，统一 mm。模版预览规格用于验收，不应被误当成禁止城市自定义规格；遇到不适配的比例应返回排版问题。

## 模版生成

同时生成可复用项目模版配置、素材引用、预览及检查结果，不仅保存一张 PNG。模版结构至少包含：

- 模版标识和版本、网区/项目归属。
- 主视觉引用及实际版本；固定品牌资产和规则版本。
- 选定基础版式和品牌排列。
- 默认内容、必填字段、城市可编辑字段和锁定字段。
- 验收预览规格及城市尺寸输入策略。
- 网站维护的状态、发布时间、有效性信息和确认记录。

新模版在网站分配 ID/版本之前，可以返回本地草稿标识；该标识只用于本地关联，不能伪称网站正式 ID。修改已发布模版需要网站分配新版本；不覆盖旧版本而破坏城市任务追溯。

调用同一排版引擎为验收规格生成真实预览和无水印候选 PNG，记录路径与文件指纹，再按 [审核交接](audit-rules.md) 调用独立 `didi-design-audit`，返回对应文件的审核报告。自由活动说明、二维码图片或其他未适配组件必须明确列入待接入项，不能生成一个丢失内容的“完整模版”。

## 预览确认

展示实际预览和审核结果，让制作者确认对应的模版版本。确认记录至少关联版本、预览规格和素材版本。确认后发生主视觉、版式、内容默认值或编辑限制等影响画面的修改，需要重新确认修改后的版本。

现有规则仍处于 draft，但预览及下载均不添加系统水印。比例回退、主体裁切、反白字在图片上的可读性等需要在预览中明确检查；没有做视觉检查时不能编造“视觉验收通过”。

## 发布资产

用户已确认：网区制作者预览确认后可直接发布，不添加额外的设计审核人或管理员审批步骤。

收到明确发布指令、独立审核报告与制作者确认记录均对应当前版本及文件，且网站授权通过时，调用环境实际提供的发布能力。有阻断失败或必需检查未完成时，先返回待处理事项；不把未通过审核的版本宣称为已通过并发布。不要为同一项已授权发布重复请求确认。发布字段和授权以真实接口为准，不虚构 HTTP 地址、令牌或接口成功结果。

- 接口成功且返回正式 ID、版本、`published_at` 和发布状态：记录为已发布，可由网站纳入后续推荐。
- 接口拒绝或失败：保留草稿与实际错误，不记录为已发布。按实际接口说明处理重试，不反复提交未知结果的请求。
- 没有发布接口：交付配置、素材和预览，状态为 `awaiting_site_integration`，具体注明缺少资产发布接入。

上传时间与发布时间分别记录。城市推荐使用网站记录的最新发布时间，不能用文件修改时间或最新上传的未发布草稿替代。
