# 城市线下物料制作

仅在执行 `material_generation` 时读取本文；共用字段见 [数据与接入约定](contracts.md)。

## 确认需求

网站提供已确认的需求、任务身份、选定项目模版的 ID、版本及完整配置，或可读取该配置的引用。网站按同网区、同项目下最新发布且有效的版本推荐；Skill 不另行挑选“最新”。

检查模版归属与任务信息一致、引用版本可读取，使用网站提供的权限与有效性结果。没有可信的这些结果时返回缺失信息或待接入项，不假装完成服务端鉴权。任务以确认时的网站绑定记录为准；后续下架、失效能否继续生成由网站判定。

城市覆盖字段仅为 `title`、`subtitle`、`qr`。未提供的字段继承模版默认值；显式空值只有在该字段非必填时才表示清空。覆盖主视觉、版式、日期地点或其他锁定字段时报告字段错误，不能静默忽略后宣称按要求完成。

合并后的 `title` 固定必填，必须是非空白字符串；这一要求不能被模版覆盖。附加必填项来自模版 `required_fields`；未定义时按仅主标题必填执行，不擅自要求副标题或二维码必填。显式清空主标题返回 `TITLE_REQUIRED`，保留模版默认标题则满足内容输入要求。

二维码模式为 `link` 或 `image`。输入图片时先确认环境有二维码图片绘制适配；没有适配时保留输入，返回待接入信息，不能用空白二维码、占位图或猜测链接替代。

### 物料与尺寸输入

用户已指定网站表单形式：按物料类型分组，每组有预设规格和“自定义”；可新增物料类型，可选多个规格。网站最终输出 `targets` 扁平清单，每个已选规格对应一个独立条目。

所有 `targets[].unit` 均为 `mm`，包括大屏。宽、高按输入顺序保留，不自动交换方向。网站可以调整预设列表，Skill 不维护另一套默认目录。

用户截图中的列表用于说明网站输入形式：

| 类型 | 截图预设规格，单位 mm |
| --- | --- |
| 台卡 | 210×297、148×210、100×200 |
| 易拉宝 | 800×2000、600×1600 |
| 灯箱 | 1200×1800、2400×1200 |
| 大屏 | 3500×1500、6000×3000 |

以上不是每次任务默认选中清单。只处理网站传入的已选项。自定义类型需要明确名称；自定义尺寸需要明确正数宽高。数量上限、尺寸上限由网站的实际策略传入，不从旧文档试举的“最多 6 个”“50—3000”推定；不能据此排除截图中的 6000 mm。

## 设计生成

1. 将项目模版与城市允许的覆盖内容合并，记录本次实际使用的模版、规则和素材版本。项目模版 ID 保存在任务元数据中；`splitPreset` 必须取模版配置的 S/M/L/XL。
2. 按 [配置与调用](../docs/02-配置与调用.md) 准备浏览器环境、字体、图片和必要的二维码适配。没有浏览器渲染环境时，不声称完成真实字体排版或 PNG 导出。
3. 对每个规格调用 `DidiLayout.plan(data, target)`。保留锁定版式，由引擎根据目标比例适配横竖方向；不擅自选择另一种 S/M/L/XL。
4. 没有阻断错误且字体实际加载后，调用 `render()` / `exportPng()` 生成真实预览与无水印候选 PNG，保存实际路径、像素尺寸及文件指纹；候选文件暂不作为审核通过的正式下载。导出失败据实记录。
5. 将逐规格问题和实际候选文件交给独立审核。错误画面可以作为带问题标识的诊断预览，不提供为通过审核的成品。预检查 → 候选导出 → 成品审核是现有页面流程内部的执行顺序，不新增用户操作步骤。

当前引擎的 `details` 来自 `date` 和 `location`；自由活动说明字段尚未接入。模版存在引擎不支持的内容时明确返回，不丢弃内容。

## 自动审核

按 [独立审核交接](audit-rules.md) 调用 `didi-design-audit`。将需求与模版版本、规则快照、逐规格布局结果、真实预览和下载文件一并交给审核，接收绑定文件指纹的逐项报告。独立审核不可用时明确返回缺少接入，不把生成预检查冒充审核。

- 排版 `error`：该规格审核失败，不导出为通过结果。
- 草稿比例回退或需设计确认的视觉问题：记录 `needs_review`，不能因 `layout.valid = true` 就称完整审核通过。
- 文案过长：指出字段和行数/区域问题，建议城市精简主副标题。不能建议城市修改其没有编辑权的日期、主视觉或版式；此类问题交回网区。
- 二维码的生成/绘制失败：不能把“链接待检查”占位符当有效二维码。

## 查看结果

为每个已选规格返回类型、宽高 mm、对应 PNG 像素尺寸、预览、实际生成文件、审核明细和下一步建议。独立报告通过且文件指纹仍一致时，才把候选 PNG 提供为该规格的正式下载；失败或待确认时展示问题和诊断预览，不标记成品通过。正式下载无系统水印，保持 72 dpi；将正式设计文件与印前验收状态分别记录。

文件名可包含物料类型、宽高、任务 ID 和版本，以免同一批不同规格互相覆盖；类型名称只作文件名数据处理。存在重复规格时仍按独立 `item_id` 关联结果，不静默删除用户选项。

用户修改主副标题或二维码后，对受影响规格重新生成和审核；已确认的项目模版版本保持不变。保存/查询历史由网站接口完成，接口缺失时返回本地结果位置。
